## 3. The diagnosis, step by step

### 3.1 Is it alive? Load and memory

```bash
uptime          # load average
free -h         # memory
htop            # who is consuming
```

### 3.2 Is there disk space?

```bash
df -h
sudo du -xh / --max-depth=2 | sort -h | tail -20
```

### 3.3 What do the logs say?

```bash
journalctl -u nginx --since "10 min ago"
sudo tail -f /var/log/syslog
```

### 3.4 Who owns the port?

```bash
sudo ss -tulpn | grep :80
```

## 5. Cheat sheet

| Symptom | Command |
| ------- | ------- |
| Slow | `uptime`, `htop` |
| Disk full | `df -h`, `du` |
| Service won't start | `systemctl status`, `journalctl -u` |
| Port in use | `ss -tulpn` |
