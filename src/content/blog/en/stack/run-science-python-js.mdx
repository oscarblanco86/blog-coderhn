## 4. The same function, idiomatic in each language

```python
# python/src/run_science/hr.py
def karvonen(rest_hr: float, max_hr: float, intensity: float) -> int:
    if max_hr <= rest_hr:
        raise ValueError("max_hr must be greater than rest_hr")
    if not 0 <= intensity <= 1:
        raise ValueError("intensity must be between 0 and 1")
    return round(rest_hr + intensity * (max_hr - rest_hr))
```

```ts
// js/src/hr.ts
export function karvonen(restHr: number, maxHr: number, intensity: number): number {
	if (maxHr <= restHr) throw new RangeError('maxHr must be greater than restHr');
	if (intensity < 0 || intensity > 1) throw new RangeError('intensity must be between 0 and 1');
	return Math.round(restHr + intensity * (maxHr - restHr));
}
```

TODO: watch out for rounding. Python's `round()` uses banker's rounding (2.5 → 2) while JS's
`Math.round` doesn't (2.5 → 3). That's exactly the kind of difference shared vectors catch.
