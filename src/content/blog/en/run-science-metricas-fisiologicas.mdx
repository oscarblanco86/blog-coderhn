## 3. The proposed solution (architecture)

```text
run-science/
├── vdot/        → VDOT from a race result (distance + time) and training paces
├── hr/          → heart-rate reserve and Karvonen zones
└── units/       → pace / speed / distance conversion
```

**Key decision:** pure functions that take and return SI units, with unit conversion isolated in
its own module. That keeps the physiology logic separate from presentation formatting.

## 4. Key code

The Karvonen formula computes a zone's target heart rate from the heart-rate reserve:

```ts
/**
 * Target HR = resting HR + intensity × (max HR − resting HR)
 * @param intensity fraction between 0 and 1 (e.g. 0.7 = 70 %)
 */
export function karvonen(restHr: number, maxHr: number, intensity: number): number {
	if (maxHr <= restHr) throw new RangeError('maxHr must be greater than restHr');
	if (intensity < 0 || intensity > 1) throw new RangeError('intensity must be between 0 and 1');
	return Math.round(restHr + intensity * (maxHr - restHr));
}
```

And its test:

```ts
import { expect, test } from 'vitest';
import { karvonen } from './hr';

test('zone 2 (60–70 %) for resting HR 50 and max HR 190', () => {
	expect(karvonen(50, 190, 0.6)).toBe(134);
	expect(karvonen(50, 190, 0.7)).toBe(148);
});
```
