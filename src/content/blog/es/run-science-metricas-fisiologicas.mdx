## 1. El problema

Las apps de running calculan ritmos y zonas de frecuencia cardiaca, pero lo hacen como una caja
negra: no puedes auditar la fórmula, ni reutilizarla en tu propio proyecto (por ejemplo, la
plataforma de un club o un análisis de datos de Strava).

## 4. Código clave

La fórmula de Karvonen calcula la FC objetivo de una zona a partir de la frecuencia cardiaca de reserva:

```ts
/**
 * FC objetivo = FC reposo + intensidad × (FC máx − FC reposo)
 * @param intensity fracción entre 0 y 1 (ej. 0.7 = 70 %)
 */
export function karvonen(restHr: number, maxHr: number, intensity: number): number {
	if (maxHr <= restHr) throw new RangeError('maxHr debe ser mayor que restHr');
	if (intensity < 0 || intensity > 1) throw new RangeError('intensity debe estar entre 0 y 1');
	return Math.round(restHr + intensity * (maxHr - restHr));
}
```

Y su prueba:

```ts
import { expect, test } from 'vitest';
import { karvonen } from './hr';

test('zona 2 (60–70 %) para FC reposo 50 y FC máx 190', () => {
	expect(karvonen(50, 190, 0.6)).toBe(134);
	expect(karvonen(50, 190, 0.7)).toBe(148);
});
```
