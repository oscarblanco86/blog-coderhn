## 2. ISO 9000, 9001 y 90003: qué es cada una

- **ISO 9000**: fundamentos y vocabulario de la gestión de la calidad. Define los 7 principios.
- **ISO 9001**: los requisitos de un sistema de gestión de la calidad. Es la que se certifica.
- **ISO/IEC 90003**: guía para aplicar ISO 9001 al software. TODO: confirmar versión vigente.

## 3. Los 7 principios, traducidos a un equipo de desarrollo

| Principio | En un equipo de software |
| --- | --- |
| Enfoque al cliente | Criterios de aceptación escritos con el usuario; métricas de uso reales |
| Liderazgo | Definición de "hecho" compartida y defendida por el equipo |
| Compromiso de las personas | Revisiones de código como aprendizaje, no como control |
| Enfoque a procesos | Un flujo único: issue → rama → PR → CI → deploy |
| Mejora | Retrospectivas con acciones que se cierran |
| Decisiones basadas en evidencia | Métricas DORA, cobertura, errores en producción |
| Gestión de las relaciones | Acuerdos claros con proveedores y dependencias (SLA, versiones fijadas) |

## 4. Cláusulas de ISO 9001 → prácticas → evidencia

| Cláusula | Qué pide | Práctica | Evidencia que se genera sola |
| --- | --- | --- | --- |
| 6.1 Riesgos y oportunidades | Pensar en lo que puede fallar | Revisión de riesgos en el diseño | Sección "riesgos" en el ADR |
| 7.5 Información documentada | Documentos controlados y versionados | ADRs y README en el repo | Historial de git |
| 8.3 Diseño y desarrollo | Planificar, revisar, verificar y validar | PRs con revisión obligatoria y tests | PRs aprobados + checks de CI |
| 8.5.6 Control de cambios | Cambios revisados y trazables | Ramas protegidas, commits enlazados a issues | Log de merges |
| 8.7 Salidas no conformes | Que lo defectuoso no llegue al cliente | Feature flags, `draft: true`, rollback | Deploys bloqueados por CI |
| 9.1 Seguimiento y medición | Medir el desempeño | Métricas DORA | Tablero |
| 9.2 Auditoría interna | Revisar que el sistema funciona | TODO: auditoría trimestral ligera | Informe en el repo |
| 10.2 No conformidad y acción correctiva | Causa raíz y corrección | Postmortems sin culpas | Issue etiquetado + test de regresión |
