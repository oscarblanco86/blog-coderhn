## 2. Arquitectura del pipeline

```text
PR ──▶ lint + tests ──▶ build ──▶ netlify deploy (preview) ──▶ Lighthouse CI ──▶ ✅ / ❌
main ─▶ (lo mismo) ─────────────▶ netlify deploy --prod
```

## 3. Deploy de preview desde Actions

```yaml
      - name: Deploy preview
        run: bunx netlify-cli deploy --dir=dist --json > deploy.json # TODO: verificar flags
        env:
          NETLIFY_AUTH_TOKEN: ${{ secrets.NETLIFY_AUTH_TOKEN }}
          NETLIFY_SITE_ID: ${{ secrets.NETLIFY_SITE_ID }}
```

## 4. Lighthouse como portero

```json
{
	"ci": {
		"assert": {
			"assertions": {
				"categories:performance": ["error", { "minScore": 0.95 }],
				"categories:accessibility": ["error", { "minScore": 1 }]
			}
		}
	}
}
```
