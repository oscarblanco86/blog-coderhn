## 3. De README a workflow

Antes (README):

```text
1. docker compose up -d db
2. export DATABASE_URL=...
3. python manage.py migrate
4. python manage.py runserver 0.0.0.0:8000
```

Después (workflow parametrizado):

```yaml
# TODO: validar formato actual de workflows de Warp
name: Levantar proyecto
command: docker compose up -d db && python manage.py migrate && python manage.py runserver 0.0.0.0:{{port}}
arguments:
  - name: port
    default_value: '8000'
```
