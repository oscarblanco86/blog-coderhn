## 2. El pipeline inicial (lento)

```yaml
# .github/workflows/ci.yml — versión 1
name: CI
on: [push, pull_request]
jobs:
  all:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: bun install
      - run: bun run lint
      - run: bun run test
      - run: bun run build
```
