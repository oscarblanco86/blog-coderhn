## 4. La misma función, idiomática en cada lenguaje

```python
# python/src/run_science/hr.py
def karvonen(rest_hr: float, max_hr: float, intensity: float) -> int:
    if max_hr <= rest_hr:
        raise ValueError("max_hr debe ser mayor que rest_hr")
    if not 0 <= intensity <= 1:
        raise ValueError("intensity debe estar entre 0 y 1")
    return round(rest_hr + intensity * (max_hr - rest_hr))
```

```ts
// js/src/hr.ts
export function karvonen(restHr: number, maxHr: number, intensity: number): number {
	if (maxHr <= restHr) throw new RangeError('maxHr debe ser mayor que restHr');
	if (intensity < 0 || intensity > 1) throw new RangeError('intensity debe estar entre 0 y 1');
	return Math.round(restHr + intensity * (maxHr - restHr));
}
```

TODO: ojo con el redondeo. `round()` de Python usa redondeo bancario (2.5 → 2) y `Math.round` de JS
no (2.5 → 3). Este es exactamente el tipo de diferencia que atrapan los vectores compartidos.
