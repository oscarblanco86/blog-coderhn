## 4. La API en 20 líneas

```python
# app.py
from flask import Flask, jsonify, request
from vdot import vdot

app = Flask(__name__)

@app.get("/vdot")
def calc_vdot():
    try:
        distance = float(request.args["distance_m"])
        time = float(request.args["time_s"])
    except (KeyError, ValueError):
        return jsonify(error="distance_m y time_s son obligatorios y numéricos"), 400
    return jsonify(vdot=round(vdot(distance, time), 1))
```

```bash
flask --app app run --debug
curl "http://127.0.0.1:5000/vdot?distance_m=10000&time_s=2700"
```
