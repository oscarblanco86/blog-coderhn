## 3. El diagnóstico, paso a paso

### 3.1 ¿Está vivo? Carga y memoria

```bash
uptime          # load average
free -h         # memoria
htop            # quién consume
```

### 3.2 ¿Hay disco?

```bash
df -h
sudo du -xh / --max-depth=2 | sort -h | tail -20
```

### 3.3 ¿Qué dicen los logs?

```bash
journalctl -u nginx --since "10 min ago"
sudo tail -f /var/log/syslog
```

### 3.4 ¿Quién ocupa el puerto?

```bash
sudo ss -tulpn | grep :80
```
